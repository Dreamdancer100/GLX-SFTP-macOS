## 📖 About GLX SFTP macOS

### Your everyday server tool

GLX SFTP is the program for everyone who looks after websites, home servers, Proxmox, Raspberry Pi or rented virtual servers. You connect via SFTP and SSH, see on the left and right exactly what you need right now, and keep all servers neatly organised in folders on the left. No more jumping between PuTTY, WinSCP and FileZilla.

### Two panes, freely selectable

Each connection opens in its own tab. Inside, two panes side by side show either the files on your Mac, the files on the server or the SSH terminal. You switch with one click right above the pane, and another click swaps left and right.

Work like with a classic FTP program (Mac left, server right) or like with MobaXterm or Cyberduck (server files and terminal). Drag the divider with the mouse; GLX SFTP remembers your choice for the next connections.

### Simply drag files across

Drag files and whole folders from the Mac pane to the server pane and back, directly into a subfolder if you like. You can also drag files in from the Finder. Uploads first go under a temporary name, so there is never a half file on the server.

A bar shows every transfer with progress, speed and remaining time, and each one can be cancelled. If a file already exists, you decide: overwrite or skip.

### Edit files directly on the server

A double-click opens a file from the server in your usual program, for example a configuration, a script or an HTML page. After saving, GLX SFTP asks whether the change should go to the server. On top come new folders, rename, delete, change permissions (also as a number such as 644) and showing or hiding hidden files.

### Terminal with its own designs

The SSH terminal works as usual, also with programs such as nano, htop or mc. Selected text is copied to the clipboard immediately, a right-click pastes. Choose from 12 colour designs, font, font size and cursor. Every server can get its own design, so you always see at once which machine you are working on.

### SFTP, SSH, FTP and FTPS

Besides SFTP and SSH, GLX SFTP also speaks FTP and FTPS, explicit and implicit via port 990, for example for webspace without SSH access. Log in with a password or a key (PuTTY .ppk and OpenSSH).

### Take over all servers in a few clicks

You don't have to type anything. GLX SFTP finds the saved servers from PuTTY, KiTTY, MobaXterm, WinSCP, FileZilla, Cyberduck and the OpenSSH config file. Tick what you want to take over, and the folders from the old program are kept. Exported files from another Mac can be loaded too.

The other way round, GLX SFTP also saves your server list for these programs, for example for a colleague who still uses PuTTY or FileZilla. Passwords are never passed on.

### Favourites, folders and your own icons

Your servers are listed on the left, sorted in folders and any number of subfolders, reordered by dragging. A search finds every server instantly, a double-click connects.

Every server and folder can get its own icon. More than 300 icons in categories are included, and you add your own images (PNG, SVG, ICO, JPG and more) in your own libraries. You can even give the buttons in the top bar your own icons.

### Secure from the start

Passwords are stored encrypted, only your own user account can read them. On the first connection GLX SFTP shows the server's fingerprint and remembers it. If the server later reports differently, no connection is made. The same applies to certificates with FTPS.

### Pleasant to use

12 program designs from light to dark, German and English, detailed in-app help with search and tooltips on every button. The window adapts to any size; when it gets smaller, the buttons move closer together. GLX SFTP runs only once, every further connection opens as a tab.

### Try it now for 14 days

You can try GLX SFTP for 14 days with all features free of charge. After that your favourites, icons and settings remain; to connect and transfer you need the full version. Updates come directly in the program.

## ✨ Features

- 🚀 **Two panes:** Mac files, server files or terminal on each side, with swap and ready-made views.
- 🧩 **Drag from Finder:** Drag files between Mac and server, also straight from Finder.
- ⚙️ **Copy, cut and paste:** On the server and on your Mac with Cmd+C, Cmd+X and Cmd+V; pasting into the other pane transfers the files.
- 🔒 **Never overwrites by accident:** Existing names get a copy suffix; deleting on the Mac moves files to the Trash.
- 📂 **SFTP, SSH, FTP and FTPS:** Explicit and implicit FTPS on port 990, SSH terminal included.
- ⚡ **Import your servers:** From FileZilla, Cyberduck, OpenSSH config and exports of PuTTY, KiTTY, MobaXterm and WinSCP; save them back for those programs.
- 🎨 **Favourites with icons:** Folders, 300+ included icons and your own icon libraries.
- 🌍 **Mac shortcuts:** Cmd+N new connection, Cmd+K quick connect, Cmd+W disconnect, Cmd+Backspace delete.
- 🛠️ **Native Mac app:** Intel and Apple silicon, Mac window buttons, runs once and brings the open window to the front.
- 📊 **12 designs, two languages:** German and English, built-in help, 14-day trial.
